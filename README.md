# Toymoil

Toymoil 是一款正在从零设计的 cute-tech 2.5D 动作游戏。

它希望把真实立体的 3D 世界，与具有明确像素轮廓的 2D Sprite 角色、武器、
敌人和特效结合起来。地图可以混合使用 GridMap、Mesh、Decal 与 Sprite；角色
可以在具有高度、楼梯、高台、坑洞和遮挡的空间中行动。

这个仓库的 main 分支目前只有产品文档、制作方法和空目录骨架，没有 Godot
项目、代码、场景、资产或可运行内容。实现将在本地开发学习分支中，从最小原型
开始逐步建立。
