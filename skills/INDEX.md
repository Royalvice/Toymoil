# Toymoil Skills

这些 Skills 保存可复用的制作方法和验收问题，不绑定尚未存在的 Godot 类、路径或
框架。开发分支可以在真实工作暴露重复问题后扩展它们。

| Skill | 用途 |
|---|---|
| asset-source | 记录来源、许可、hash 和公开边界 |
| normal-map | 为像素 Sprite 制作和验证法线贴图 |
| sprite-packet | 定义 Sprite 动作、方向、时序和锚点资料 |
| presentation-review | 审查 Sprite、灯光、遮挡和 VFX 可读性 |
| scene-authoring | 保证持久内容在 Godot 编辑器中所见即所得 |
