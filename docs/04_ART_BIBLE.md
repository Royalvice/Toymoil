# Toymoil 美术圣经

## Cute-tech

Toymoil 的科技不是冷漠的工业写实，而是可触摸、可理解、略带玩具感的机械世界。
结构应清楚表达用途，危险与奖励有稳定的视觉语言，角色在复杂场景中仍然亲近、醒目。

## 视觉支柱

- 清晰轮廓：角色在静止、移动、受击和攻击时都能凭剪影识别。
- 有限层级：颜色和亮度承担身份、危险、奖励与背景层级，不平均用力。
- 像素纪律：避免模糊缩放、亚像素抖动和无法稳定显示的微小特征。
- 真实空间：接触阴影、遮挡、高差和环境结构帮助解释角色所在位置。
- 克制光影：灯光增加体积和氛围，但不吞没 Sprite 原始配色。

## 角色与动画

玩家、敌人、武器和主要战斗 VFX 以 2D Sprite 为主。方向数量、帧尺寸、角色屏幕
高度和动画帧数在原型阶段比较后决定，不在美术基线中锁死。

角色脚底是世界定位基准。手、武器、枪口、阴影和命中特效应使用明确锚点，避免
动画切换时漂移。若采用分层手部和武器，遮挡顺序必须随朝向稳定变化。

## 环境

3D 结构负责体积、碰撞、高度和主要遮挡。贴图、Decal 与环境 Sprite 负责图案、
磨损、标志、植物、屏幕、火焰和其他适合像素动画的细节。两者必须共享比例、色阶
和边缘语言，不能像来自两个互不相关的游戏。

## 灯光与材质

需要受灯光影响的 Sprite 应提供与 diffuse 对齐的法线或等价的受限光照数据；明确
的 Unlit 内容可以例外。彩色光主要改变明暗和边缘响应，不应把脸部或身份色完全染成
环境灯颜色。

避免依赖过强 Bloom、景深、运动模糊或抗锯齿掩盖素材问题。战斗主体在关闭后处理时
仍应清楚成立。

## VFX 信息层级

- 持续弹体：最小但持续可追踪。
- 攻击预警：比弹体更早、更稳定，明确危险区域与时机。
- 命中反馈：短促、集中，不长期遮挡角色。
- 大招、清场和失败：可以占据最高层级，但必须保持结果可解释。

## 视觉验收问题

- Sprite 是否在任何可达位置都没有纸片侧面？
- 玩家是否能从背景、敌人和 VFX 中立即被识别？
- 高度、脚底、遮挡和命中位置是否一致？
- 彩色灯是否保留角色身份色？
- 动画锚点、武器换侧和阴影是否稳定？
- 关闭后处理后，素材和构图是否仍然成立？
