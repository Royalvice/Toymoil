# Toymoil 愿景

## 产品身份

Toymoil 是一款 cute-tech 2.5D 动作游戏。玩家在一个真实立体、可感知高度和遮挡
的世界中行动，而角色、敌人、武器、弹体与主要特效保持清晰的 2D 像素表现。

游戏应同时具有三种感受：空间是真实而可探索的，战斗信息是清楚而有节奏的，
世界是可爱、精密、带一点实验室玩具感的。

## 核心支柱

### 真实空间

地形高度、楼梯、高台、坑洞、墙体、遮挡和弹道是玩法空间的一部分，而不是只画在
背景里的错觉。地图可以同时使用 3D Mesh 与 2D 图像细节。

### Sprite 角色

角色保留手绘或像素动画的直接表现力。无论角色位于地图何处，正式镜头都不能让
玩家看见 Sprite 像一张有侧边的纸片。

### 可读的动作

移动、攻击、危险、命中和环境层级都应容易理解。视觉密度可以高，但玩家必须知道
危险来自哪里、自己为什么受伤、下一步能够做什么。

### Agent-first 内容扩展

Toymoil 首先是一款游戏。可复用结构、文档和工具的价值，是让 Agent 能在不破坏
既有体验的前提下持续增加角色、武器、敌人、房间和 VFX。

## 设计参考

- Cassette Beasts：2D 像素角色与真实 3D 地形的结合、固定视角下的空间表达。
- Enter the Gungeon：房间遭遇、攻击预警、弹幕可读性、武器反馈与战斗节奏。
- Octopath Traveler II：HD-2D 光影、景深层次、材质与像素美术的统一。
- Triangle Strategy：Sprite 角色、立体地图、高差、遮挡和战术空间。
- Ragnarok Online：2D 角色存在于 3D 场景中的经典视觉与方向表达。
- CrossCode：高速动作、地形高度、交互反馈和战斗信息层级。
- Hades：房间构图、遭遇节奏、清晰预警和 VFX 优先级。

这些参考分别提供空间、战斗和视觉问题的观察样本，不代表 Toymoil 必须采用它们的
完整类型、控制方式或镜头设置。

## 当前状态

main 分支是从零开始的产品基线，目前没有可运行游戏。第一阶段任务不是搭建完整
框架，而是用最小原型找出 Toymoil 真正舒服的镜头、Sprite 表现和空间交互。
